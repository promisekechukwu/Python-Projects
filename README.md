#Delivery Cost Calculator



##Project Overview



The Delivery Cost Calculator is a beginner-friendly Python project designed to calculate delivery costs based on different delivery factors.



The program processes delivery records containing information such as customer name, delivery location, distance, package weight, delivery type, location category, and customer type.



It then uses these details to calculate the total cost of each delivery.



##Project Objectives



The main objective of this project is to apply Python fundamentals to a practical logistics problem.



The program is designed to:

• Validate delivery information.

• Calculate distance charges.

• Calculate package weight charges.

• Calculate delivery type charges.

• Calculate location charges.

• Calculate the subtotal.

• Apply customer discounts.

• Calculate the final delivery cost.

• Process multiple delivery records.

• Generate delivery cost reports.



##Delivery Cost Calculation



The delivery cost is calculated using several components:

• Base Cost – the starting cost for every delivery.

• Distance Charge – determined by the delivery distance.

• Weight Charge – determined by the package weight.

• Delivery Type Charge – based on whether the delivery is Standard, Express, or Same Day.

• Location Charge – based on whether the delivery is Local, Regional, or Inter-State.

• Customer Discount – Premium customers receive a discount based on the subtotal.



The program first calculates the subtotal and then subtracts the applicable customer discount to determine the final delivery cost.
